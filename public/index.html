Get started

Two commands to your first trace.

Install with Helm on Kubernetes, or with Docker Compose on a single machine. Then point your OpenTelemetry SDKs at it.

Installation guide
Terminal 
$ helm repo add fusescope https://fuseone-io.github.io/fusescope-charts
$ helm install fusescope fusescope/fusescope \
    -n platform --create-namespace
# then open the UI and create your first service
